# Zenith Business OS - Hızlı Başlangıç

Sistemi çalıştırmak için kök dizindeki `ZENITH_START.bat` dosyasına çift tıklamanız yeterlidir.

### Neler Yapıyor?
1. **Node.js Kontrolü**: Bilgisayarınızda gerekli çalışma ortamının olup olmadığını denetler.
2. **Otomatik Kurulum**: Eğer `node_modules` klasörü yoksa `npm install` komutunu otomatik çalıştırır.
3. **Sunucu Başlatma**: Next.js geliştirme sunucusunu aktif hale getirir.
4. **Otomatik Tarayıcı**: Uygulama hazır olduğunda varsayılan tarayıcınızda `http://localhost:3000` adresini açar.
